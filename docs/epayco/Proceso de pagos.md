# Proceso de pagos

**El proceso de pagos a través de la plataforma de ePayco** permite integrar los pagos de diferentes maneras, abarcando integraciones prediseñadas por nuestro equipo las cuales puede usar fácilmente, integraciones diseñadas por usted mismo, o empleando la experiencia de integración que le permite nuestro checkout.

El proceso de pagos en la plataforma de ePayco se realiza ejecutando el **siguiente flujo**:

![](https://cdn.document360.io/88b1b912-ebe6-4677-9cf4-27af4e66c459/Images/Documentation/MicrosoftTeams-image(3).png)

**Este es un ejemplo del proceso de pago que realiza un usuario desde el Onepage Checkout:**

![](https://cdn.document360.io/88b1b912-ebe6-4677-9cf4-27af4e66c459/Images/Documentation/checkoutlisto-_1_.gif)

form -> checkout -> [wait transaction] -> estado epay -> respuesta -> pagina de confirmación transaccional
